# 换板指南：一块固件，三种硬件

> 固件从 v3 起支持**两块板**，用一行宏切换。服务端、卡片、语音、数据全部复用。

```cpp
// firmware/habit_coach/habit_coach.ino 顶部
#define BOARD BOARD_DEVKITC_GC9A01   // 参考实现：240×240 + DFPlayer + 两个按键
// #define BOARD BOARD_WS_1_85       // Waveshare 1.85" 触摸板：360×360 + 触摸 + I2S + TF
```

---

## 一、两块板对照

| | DevKitC + GC9A01 | Waveshare 1.85C（带外壳，推荐） | Waveshare 1.85 裸板 |
|---|---|---|
| 主控 | ESP32-S3 N16R8 | ESP32-S3R8（16MB Flash + 8MB PSRAM） |
| 屏幕 | GC9A01 **SPI** 240×240 | ST77916 **QSPI** 360×360 |
| 交互 | 2 个实体按键 | **CST816 电容触摸**（轻点/长按） |
| 语音 | DFPlayer（SD 卡里点播 mp3） | **PCM5101 I2S + 功放 + 8Ω2W 喇叭** |
| 存储 | DFPlayer 自带 TF | **TF 卡（SDMMC，ESP32 直读）** |
| 计时 | NTP（断网就没提醒） | **PCF85063 RTC（断网也能提醒）** |
| 便携 | 需外接电源 | MX1.25 锂电池 + 充电管理 |
| 外壳 | 无 | **音箱盒 + 4Ω5W 喇叭 + 电池仓** | **无后盖（裸板）** |
| 成本 | ≈¥125（散件） | 约 ¥180–220 | ¥139（裸板） |
| 适合 | 验证产品逻辑、改代码最快 | 最终形态、撑到 8 岁 |

## 一点五、买哪个 SKU（1.85 有四个版本）

| SKU | 版本名 | 含什么 | 建议 |
|---|---|---|---|
| 30683 | Standard version | 只有板子，**没有后盖** | ❌ 别买（裸板、焊点外露） |
| **30684** | **With speaker box + 3.7V 锂电** | **外壳 + 4Ω 5W 喇叭 + 电池** | ✅ **首选** |
| **30685** | With speaker box（不含电池） | 外壳 + 喇叭 | ✅ 次选（自己配 MX1.25 电池） |
| — | 1.85C-BOX | 上面两个套装的统称 | — |

搜索关键词：`ESP32-S3-Touch-LCD-1.85C` 或 `1.85C-BOX`。

> **为什么 30683 不行**：给孩子放在床头的东西，板子背面焊点和排针裸露，没有后盖——
> 安全和"成品感"都不过关。多花几十块买带盒版，省掉 3D 打印后盖的麻烦。

## 二、1.85 / 1.85C 的硬件连接（来自 Waveshare wiki）

**1.85 与 1.85C 的屏幕、TF 卡、麦克风、喇叭引脚完全一致**，只有两处不同：

| 信号 | 1.85（裸板） | **1.85C（带盒）** |
|---|---|---|
| TP_SDA / TP_SCL | GPIO1 / GPIO3（独立 I2C 总线） | **GPIO11 / GPIO10（与 TCA9554/RTC 共用主 I2C）** |
| RTC_INT | GPIO9 | EXIO4 |
| 扬声器 | 8Ω 2W | **4Ω 5W** |
| 额外 | — | 1.27mm 28PIN 插座、MP1605 电源模块、电池开关 |

固件里用 `TP_ON_SYS_BUS` 区分：1.85C 的触摸直接挂在 `Wire` 上，1.85 用独立的 `Wire1`。


**屏幕 ST77916（QSPI）**

| 信号 | GPIO | | 信号 | GPIO |
|---|---|---|---|---|
| LCD_SDA0 | 46 | | LCD_SCK | 40 |
| LCD_SDA1 | 45 | | LCD_CS | 21 |
| LCD_SDA2 | 42 | | LCD_BL | 5 |
| LCD_SDA3 | 41 | | **LCD_RST** | **EXIO2**（不是 GPIO！） |

**触摸 CST816（独立 I2C）**

| 信号 | GPIO |
|---|---|
| TP_SDA | 1 |
| TP_SCL | 3 |
| TP_INT | 4 |
| **TP_RST** | **EXIO1** |

**I2S 音频（PCM5101）**：BCK=48, LRCK=38, DIN=47
**TF 卡（SDMMC 1 线）**：CLK=14, CMD=17, D0=16, **CS/D3=EXIO3**
**系统 I2C（TCA9554 / RTC / IMU）**：SDA=10, SCL=11

### ⚠️ 关键坑：RST 和 SD_CS 挂在 I/O 扩展器上

`LCD_RST`、`TP_RST`、`SD_CS` 都不在 GPIO 上，而在 **TCA9554PWR**（I2C 地址 0x20）的 P1/P2/P3。

所以**必须先把 TCA9554 配好、把复位脚拉高，屏幕才会亮**。固件里的顺序是：

```cpp
tca9554Init();          // 1) 配置 P1/P2/P3 为输出，先拉低再拉高
pinMode(LCD_BL, OUTPUT); digitalWrite(LCD_BL, HIGH);
gfx->begin();           // 2) 再初始化屏幕
```

`tca9554Init()` 里写的是：

| 寄存器 | 值 | 含义 |
|---|---|---|
| 0x03（配置） | `0b11110001` | P1/P2/P3 = 输出，其余输入 |
| 0x01（输出） | `0b00001110` | TP_RST / LCD_RST / SD_CS 拉高 |

> **这两个值是按位推断的，没在真机上验证过。** 第一次点亮时如果屏黑，串口会打印
> `[tca9554] cfg=.. out=..`，拿它对一眼 Waveshare 官方 demo 的写法。

## 三、要改的地方（如果你自己移植）

| 层 | 工作量 | 说明 |
|---|---|---|
| 显示驱动 | 小 | 换 `Arduino_ESP32QSPI` + `Arduino_ST77916`，其余一样 |
| 布局 | 小 | 所有坐标乘 `K()`（`SCREEN_W/240`），已做好 |
| 卡片 | **0** | 设备请求 `?s=360`，服务端按 360 渲染（259200 字节） |
| 音频 | 中 | DFPlayer → TF 卡 + I2S（需要 `ESP32-audioI2S` 库） |
| 触摸 | 小 | CST816 轮询手势，映射成和按键一样的 1/2 事件 |
| 协议 | **0** | 完全复用 |

**卡片尺寸自动适配**：固件按 `SCREEN_W` 请求 `GET /api/card.rgb565?i=0&s=360`，
服务端只认 240 / 360，其他值回落到 240。测试覆盖：

```
/api/card.rgb565?i=0&s=360 → 259200 字节
/api/card.rgb565?i=0&s=999 → 115200 字节（回落）
```

## 四、触摸怎么用（给 5 岁半）

| 手势 | 主界面 | 卡片模式 |
|---|---|---|
| **轻点屏幕** | = 按 A（我做到了） | 翻到下一页 |
| **长按 0.9 秒** | = 按 B（切换习惯） | 退出卡片 |

设计理由：5 岁半对"点一下"的理解远好于"按哪个键"，而卡片模式里翻页是高频动作。

## 六、首次点亮 checklist（1.85）

1. 烧 `hardware-test/0_board_check` → 确认 **Flash 16MB / PSRAM 8MB / 115KB 分配 OK**
2. 烧完整固件，串口按顺序看：
   ```
   [tca9554] cfg=F1 out=0E      ← 扩展器写成功
   [ui] canvas OK（或 FAIL）
   [touch] CST816 OK
   [audio] TF + I2S OK（需要装 Audio 库 + 卡里有 mp3/）
   [wifi] ok ip=...
   ```
3. 屏黑？**先看 `[tca9554]` 那行**——cfg 不是 F1 说明扩展器没写进去（检查 I2C 10/11 和地址 0x20）。
4. 屏亮了但没声音？先确认 TF 卡是 FAT32 且根目录有 `mp3/0001.mp3`。
5. 触摸没反应？`[touch] CST816 未找到` → 检查 TP_SDA/SCL（1/3）和 TP_RST（EXIO1）。
