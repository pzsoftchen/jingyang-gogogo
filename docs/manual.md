## 五、三步跑起来

### 第 1 步：准备 SD 卡（2 分钟）
把 [`voice-pack/mp3/`](../voice-pack/mp3/) 整个文件夹拷到 SD 卡根目录，命名为 `mp3`：
```
SD卡/
└── mp3/
    ├── 0001.mp3   # 早上好
    ├── 0002.mp3   # 该刷牙啦
    ├── ...
    └── 0040.mp3
```
插到 DFPlayer 上，先别装进外壳。

### 第 2 步：烧固件
1. Arduino IDE 2.x → 开发板管理器安装 **esp32 by Espressif**（3.3.x 或更新）
2. 库管理器装：**Arduino_GFX_Library**（moononournation）、**DFRobotDFPlayerMini**（DFRobot）
3. 打开 [`firmware/habit_coach/habit_coach.ino`](../firmware/habit_coach/habit_coach.ino)
4. 把 `secrets.h.example` 复制成 `secrets.h`，填 Wi-Fi 名/密码/电脑 IP
   （电脑 IP：`ipconfig getifaddr en0`；没有 `secrets.h` 也能跑，只是离线）
5. 开发板设置：
   - Board: **ESP32S3 Dev Module**
   - Flash Size: **16MB**
   - PSRAM: **OPI PSRAM**
   - Partition Scheme: **Huge APP (3MB No OTA)**
6. 上传

**先做一次离线验收**：不接服务器，按 A 键 → 星星亮、有语音、连续天数变化。这一步过了，说明硬件都通了。

### 第 3 步：起家长端
```bash
cd ~/esp32/habit-coach
python3 server.py
```
- 电脑上打开 <http://127.0.0.1:8099>
- 手机上打开 `http://<电脑局域网IP>:8099`（同一 Wi-Fi）
- 首次会提示 macOS 允许 Python 接受网络连接 → 点允许

设备开机 15 秒内会同步一次，屏幕上出现 `ONLINE` 就通了。

## 六、家长页怎么用

- **今晚就看**：今天完成几件、连续几天（全部完成才算一天）
- **发认可**：从 10 句话里点一句 → 设备在下次同步时播出来
- **备注**：写给自己看的（比如"今天老师夸他"），不会读到设备上
- **建议时长**：页面顶部有"每日 ≤30 分钟"的提醒

> 家长页没有登录，因为它只监听局域网、数据只存这台电脑的 `coach.db`。
> **不要**把 8099 端口映射到公网。

## 七、把爸妈的声音放进设备（强烈建议）

现在 0031–0040 是 Tingting 音色代读的。换成真人声音，效果完全不同：

1. 手机上录 10 条，每条 3–5 秒，安静环境、离嘴 10cm
2. 传到电脑，转成 mp3（22.05kHz 单声道即可）：
   ```bash
   ffmpeg -i 我录的.m4a -ar 22050 -ac 1 -b:a 32k 0031.mp3
   ```
3. 覆盖 SD 卡 `mp3/0031.mp3` … `0040.mp3`
4. 家长页上那 10 句话的文字保持不变，方便你记住第几条是哪句

**录什么**：别录"你真棒"这种空话。录具体的、带场景的、和孩子有关的——"今天你自己记得把书包收好，爸爸在门口看到了"。

## 八点二二、协议版本与向后兼容（上云预留）

`/api/state.txt` 第一行现在是版本号，最后一行前是内容包版本：

```
V=2
DATE=2026-11-02
...
PACK=voice.1
END
```

**三条约定**（改了要同步改固件）：

| # | 约定 | 为什么 |
|---|---|---|
| 1 | `V=` 永远第一行 | 固件先看版本，再决定怎么解析 |
| 2 | **新字段只追加在 END 之前**，不改已有行的顺序和含义 | 老固件遇到不认识的 KEY 直接忽略，不会错位 |
| 3 | `H=` 的 10 个字段保持不动；要加就加第 11 个（固件按 `n>=11` 判断） | 位置解析的老问题 |

`PACK=voice.N` 是**语音包版本**。设备会把它记在 NVS 里，将来 OTA 换语音包时据此判断
"我 SD 卡上的是不是最新"。

**设备身份**（同样为上云预留）：

```
GET /api/state.txt?d=s3-0001&t=<令牌>
```

- `d=` 设备号，服务器记进 `devices` 表并更新 `last_seen`
- `t=` 令牌；**服务器设了环境变量 `DEVICE_TOKEN` 才校验**，没设就不校验（POC 默认）
- 家长页 `/`、`/album`、`/quick` **永远不需要令牌**（那是给大人的）

POC 阶段一台设备，`d` 恒为 `poc`；上云后每台设备一行，天然支持多设备。

## 八点二五、孩子的问题怎么"容易地"进问题罐

问题罐最大的敌人不是技术，是**摩擦**——在公园里孩子问"为什么树叶会变黄"，家长不会掏出手机打字。
所以入口按"离问题最近"排序：

| 入口 | 摩擦 | 适合 |
|---|---|---|
| **① 手机 /quick 页** | 最低 | 99% 的情况。点输入框 → 键盘麦克风说一句 → 记下来 |
| **② 主屏幕图标** | 低 | Safari → 分享 → 添加到主屏幕，之后像 App 一样一点就开 |
| **③ iOS 快捷指令** | 极低 | 锁屏小组件 / 轻点背面 → 语音输入 → POST 到 `/quick`（见下） |
| **④ 设备长按** | 中 | 设备在身边时；只记"发生了一个问题"，内容回家补 |

**③ 快捷指令怎么配**（1 分钟）：
1. 快捷指令 App → 新建 → 添加操作「听写文本」
2. 加「获取 URL 内容」→ URL `http://电脑IP:8099/quick`，方法 POST，请求体表单：`question` = 上一步的听写结果
3. 设为「轻点背面两下」触发

**④ 设备长按的局限要清楚**：设备没有麦克风（这是红线），所以它记不下"问题是什么"，
只能记下**"他刚刚问了一个问题"这个时刻**。家长页会出现「⏳ 待补内容」，回家补一句话就行——
**内容可以补，时刻补不回来。**

## 八点三、成长阶段切换

家长页最下面「更多 → 成长阶段」，三个按钮，点了立即生效。

| 阶段 | 每天几件事 | 内容推送 | 复习间隔 | 出文字 |
|---|---|---|---|---|
| 5–6 岁 | 2 | 2 条 | 1/3/7/15 | 否 |
| 6–7 岁 | 3 | 2 条 | 1/2/4/8/15 | 否 |
| 7–8 岁 | 4 | 3 条 | 1/3/7/14/30 | 是 |

**改了阶段会发生什么**

- 习惯数量上限、每日内容推送配额、识字复习节奏**立刻跟着变**
- **不会**自动关闭你已经开着的习惯（从高阶段调回低阶段时会提示，让你自己减）
- **不会**自动换语音包——语音在 SD 卡里，需要重新生成并换卡（见下）

**换语音包（阶段升级的必经步骤）**

```bash
cd voice-pack
# 改 make_voice.sh 里的台词（句子变长、称呼变化），然后
VOICE=Tingting RATE=160 ./make_voice.sh
# 把 mp3/ 拷到 SD 卡，插回 DFPlayer
```

这是目前唯一"必须动手"的升级步骤，也是联网之后最该被自动化的一步（见 `network-strategy.md`）。

## 八点三五、每日内容推送预算（代码层）

原则：**孩子每天收到的"内容推送"≤2 条**。仪式动作（打卡、翻页）不计入——它们由孩子主动发起、可预期、1 秒完成。

| 类型 | 预算 | 说明 |
|---|---|---|
| `newchar` 新字卡 | 1/天 | 由习惯完成触发（情境学习） |
| `surprise` 每日惊喜 | 1/天 | 问题答案 > 复习卡 > 不给 |
| `praise` 家长语音 | 不限 | 真人内容，是家长的选择 |

实现：`pushes` 表 + `take_push(kind, ref)` 统一收口。配额用完就静默跳过，
不会出现"今天被推了 5 张卡"。

家长页「今天的惊喜」卡片底部会显示：`今天已推送 1/2 条内容（新字 1 + 惊喜 0），仪式动作不计入`。

调试：`sqlite3 coach.db "SELECT day,kind,ref FROM pushes ORDER BY id DESC LIMIT 10;"`

## 八点四、习惯图标与庆祝动画

**每个习惯在设备上是一个 emoji 图标**（🪥 刷牙、🧸 收玩具、🛁 洗澡…），不是一个抽象的星星。

理由：5 岁半不识字，能认出"牙刷"但认不出"第三颗星"。家长页和屏幕上用的是同一个图标，
孩子和家长看到的是同一件事。

- 图标由 `tools/gen_icons.py` 用 Apple Color Emoji 预渲染成 40×40 RGB565，
  生成 `firmware/habit_coach/habit_icons.h`（14 个图标，约 45KB）
- 设备端零字库、零缩放，直接 `draw16bitRGBBitmap` 贴图
- 完成态：金色圆环 + 右下角对勾；未完成：暗色圆环；选中：外圈橙色

**庆祝动画**：全部完成时放 1 秒的粒子扩散（20 个彩色粒子 + 笑脸），
而不是只把最后一颗图标点亮。对 5 岁半，"动起来"才叫反馈。

重新生成图标（改了 emoji 或加了新习惯）：

```bash
python3 tools/gen_icons.py     # 会同时更新 docs/img/habit_icons.png 预览图
```

改完记得在 `server.py` 的 `HABIT_PRESETS` 和 `tools/gen_icons.py` 的 `ICONS` 里保持 id 一致。

## 八点五、为什么按 5 岁半这样改

| 调整 | 原因 |
|---|---|
| 默认 **2 件**，但页面上可以切 **1–4 件** | 5 岁半注意力 5–10 分钟，两件事已是上限。**建议第 1–2 周只开「刷牙」一件**，稳定了再加第二件 |
| 收书包 → **收玩具** | 5 岁半还没有"书包"概念，但"玩具回家"看得见、2 分钟能做完 |
| 设备上**不显示连续天数** | "连续 5 天"对 5 岁半是抽象概念。改成**本周 7 个格子**，填满一个算一个 |
| 台词全部缩到 **1–4.7 秒**、语速 175→150 | 6 秒的句子会让他走神 |
| 早 07:20 起、07:30–07:45 出门准备，晚 19:10–20:30 睡前流程 | 一天三段，每段有自己的队列 |
| 每日上限 20 分钟 | 5 岁半更容易被设备吸住，留时间给真人 |
| 家长页加"5 岁半的正常表现"提示 | 防止家长把"今天会了明天又忘"当成失败 |

**5 岁半最关键的一条**：这个年龄需要**共同调节**（co-regulation），不是独立执行。
正确用法是——**你陪他一起按**，你站在旁边说"来，我们送玩具回家"，
设备只负责把这件事变得有仪式感，**它不能替代你**。

## 八点六、开几件事：随时能改，不用重烧固件

家长页最下面有两个折叠设置，第二个就是它：

```
设置：这个月开几件事（2/4）

早上
  ☐ 🌞 按时起床        07:20
  ☐ 🚪 出门流程        07:30   穿衣服(0') → 穿鞋(7') → 背书包(12')
白天
  ☐ 💧 喝水            10:00
  ☐ 🏃 户外玩 30 分钟  16:30
  ☐ 🍽 帮忙摆碗筷      17:45
晚上
  ☐ 🛁 洗澡流程        19:10   脏衣服放进洗衣机 → 洗澡
  ☐ 🧸 收玩具          19:40
  ☑ 🪥 刷牙            20:30
  ☐ 📖 睡前绘本        20:45

  ☐ 👕 自己穿衣服 / 👟 自己穿鞋 / 🧺 脏衣服 / 🛁 洗澡 / 🎒 收书包
```
> 库里 15 项可选，**同时最多开 4 件**（5 岁半扛不住更多）。

勾选 → 保存 → **设备 15 秒内自动同步**（也可以长按 B 立即同步）。变化是实时的：

**一条"流程"只算一颗星，但语音可以按分钟分步引导**：

```
07:30  洗澡流程（一颗星）      出门流程（一颗星）
       ├─ 0'  脱下来的衣服放进洗衣机   ├─ 0'  我们穿衣服啦
       ├─ 1'  该洗澡啦，脱衣服去       ├─ 7'  该穿鞋啦，左脚右脚
       └─ 完成 洗干净啦，香香的        ├─ 12' 背上书包，别忘了水壶
                                     └─ 完成 都准备好啦，我们出门
```

语音的排期写在习惯定义里：`53@0,43@7,62@12` = 第 53 号语音在第 0 分钟、
第 43 号在第 7 分钟、第 62 号在第 12 分钟。**孩子提前做完按了 A，后面几句自动取消。**

| 你改的 | 设备上的变化 |
|---|---|
| 勾选数量 | 底部星星数量跟着变（1~4 颗，会自动调大小和间距） |
| 勾哪个 | 提醒时间、提醒语音、完成语音全部来自服务器，不需要改代码 |
| 关掉某个 | 它当天的记录不再计入连续天数（历史数据保留） |

**断网也能用**：习惯表会缓存在设备 NVS 里，路由器坏了照样打卡，联网后自动补传。

> ⚠️ 开一个新习惯前，确认 SD 卡里有对应的两条语音，否则会静默无声（只会响蜂鸣器）。
> 对应关系见下面的台词表。

### 建议的上线节奏

| 时间 | 开几件 | 目的 |
|---|---|---|
| 现在 | **只开刷牙（1 件）** | 把成功率做到 100%，先建立"我会用这个" |
| 2 周后 | + 收玩具（2 件） | 开始有"两件事"的概念 |
| 上学前 | + 按时起床 / 自己穿衣服 | 衔接幼儿园/小学 |
| 需要时 | 脏衣服入洗衣机 / 晚上洗澡 / 睡前绘本 | 按当周重点轮换 |
| 稳定后 | 最多 4 件 | 不要再加，5 岁半扛不住 |

### 两个已经内置的设计

**① 脏衣服不是独立习惯，它是「洗澡流程」的第一步。**
这是行为科学里的习惯堆叠（habit stacking）：把新动作挂在已有流程的开头，
比凭空多一个打卡点容易得多。现在库里已经有现成的「洗澡流程」：

```
19:10  洗澡流程（一颗星）
       ├─ 语音 1：脱下来的衣服，放进洗衣机里
       ├─ 语音 2：该洗澡啦，我们脱衣服去
       └─ 完成： 洗干净啦，香香的！
```

想拆开单独练，用"单独版"里的「脏衣服入洗衣机」+「晚上洗澡」两项。

**② 「按时起床」对 5 岁半不是他能完全控制的事。**
起床取决于生理节律和家长唤醒，做成 KPI 会变成"考核孩子"。
用法建议：**只提醒 + 只庆祝，不追问**。他按了就按了，没按就当没这回事。

### 建议的 4 颗星（覆盖一整天的节奏）

```
07:30  出门流程       ← 早上：15 分钟准备，分三句引导（07:45 出门）
16:30  户外玩 30 分钟  ← 白天：释放精力
19:10  洗澡流程       ← 晚上：脏衣服 + 洗澡
20:30  刷牙           ← 睡前
```

早 1、白天 1、晚上 2，一天有三处"被看见"的时刻。
收玩具、绘本、按时起床作为轮换项，哪周有问题就换上去。

## 八点七、问题罐：他问的问题，回家一起找

### 为什么不做"实时问答机"

技术上：设备用 DFPlayer 播 SD 卡里的**预录** mp3，没法播动态生成的语音。
要实时问答得换成 I2S DAC + 联网流式播放，硬件和延迟都是另一个量级。

但更重要的原因是教育上的：

- 5 岁半问问题时，**"被认真对待"比"得到答案"重要**。立刻给标准答案，会把他从探索者变成"答案索取者"——这正是新华网那篇调研里家长吐槽的"答案直给"。
- 好问题往往值得停下来看一会儿。叶子为什么黄了，答案在叶子上，不在音箱里。

**所以：AI 负责让大人变聪明，大人负责陪孩子变聪明。**

### 怎么用

1. **在公园**：掏出手机，家长页最下面「问题罐」输入框，记一句"为什么树叶会变黄"
2. **回家**：点「让 AI 先写一版」（或自己写），它会按三段给出：
   ```
   一句话答案：叶子里的绿色会被太阳慢慢吃掉，黄色就露出来了。
   一个反问：  你摸摸这两片叶子，哪一片更薄？
   一起做：    捡三片不同颜色的叶子，按颜色排排队。
   ```
3. **改一改**：AI 写的只是草稿，删掉不像你会说的话
4. **保存并在设备播报** → 设备播："我们一起看看这个问题的答案吧。"
5. **你讲给他听**，边讲边做那个小动作

### 配置 AI（可选，不配也能用）

```bash
export DASHSCOPE_API_KEY=sk-xxx      # 阿里通义
# 或 export OPENAI_API_KEY=sk-xxx
# 或 export DEEPSEEK_API_KEY=sk-xxx
python3 server.py
```
不配 key 也不影响记问题——AI 那步会提示"先自己写吧"，你手写一样可以播报。

**内置的内容护栏**：如果问题涉及死亡、疾病、暴力、家庭困境、陌生人，prompt 会让它先在开头给家长一句
"怎么回答更安全"，再给三段内容。但这只是草稿，**最终说什么由你决定**。

> 问题罐还有一个副作用：翻一翻这些问题，你会看到孩子这阵子在想什么。
> 这比任何成长报告都有意思。

### 问题卡：设备上真的能看到中文问答

屏幕用的是 Arduino_GFX，默认只有 ASCII 字库。要在设备上显示中文，常规做法是塞一个
100KB+ 的点阵字库再写排版逻辑——能行，但难维护（改一版页码都要重新算）。

**换了个做法：服务器把问答渲染成图，设备只负责下载后贴屏。**

```
家长页（审核答案）
   ↓ card.py + PingFang 字体，渲染 240×240
   ↓ GET /api/card.rgb565?i=N   ← 115200 字节 RGB565
ESP32：memcpy 到 canvas 的 framebuffer，直接 flush
```

好处：

- 设备端**零字库、零排版**，中文、标点、换行全在服务器解决
- 改样式只改 `card.py`，不用重烧固件
- 一页一个想法（答案 / 你可以问问看 / 一起做），5 岁半不识字也能跟着家长念

**用法**：家长页写完答案 → 点「在设备上播放这张卡」→ 设备先播
"我们一起看看这个问题的答案吧" → 屏幕出现第 1 页 → **B 翻页，A 退出**。

预览：家长页「问题罐」下面会显示这三页的缩略图，和你手机上看到的完全一致。

调试接口：

| 接口 | 用途 |
|---|---|
| `/api/card.png?i=0` | 浏览器预览（PNG） |
| `/api/card.rgb565?i=0` | 设备下载（原始 115200 字节） |
| `/api/state.txt` 里的 `Q=3` | 告诉设备这张卡有几页 |

> 内存：115200 字节优先放 PSRAM (`heap_caps_malloc` + `MALLOC_CAP_SPIRAM`)，
> 失败会回退到内部 RAM；都不行就在串口报 `NO MEM`。

### 认一个字：5 岁半的识字包

**先划清边界**：5 岁半是"前识字"阶段，不是系统识字。
《3–6 岁儿童学习与发展指南》明确不要求提前教拼音和写字——这个年龄要做的是
**字形敏感度 + 字音字义的联结**，而不是识字量。

所以这套设计有四条硬规则：

| 规则 | 理由 |
|---|---|
| **只认，不写** | 5 岁半手部小肌肉不适合大量书写，写字会变成手酸 + 挫败 |
| **不教拼音** | 这个年龄学拼音容易和英文字母混淆，而且拼音不是识字的前提 |
| **不考试** | 别问"这个字念什么"。改成"你在哪里见过它？"——找字，不是背字 |
| **一天一个** | 间隔重复比一次教十个有效，第二天先复习昨天的 |

**选字顺序不是按笔画，而是按"动机 > 生活高频 > 象形结构"**：

```
我 / 爸 / 妈 / 家            ← 动机最强：自己的名字和家人
手 / 口 / 牙 / 脚 / 头        ← 身体：每天用、能指着说
门 / 床 / 灯 / 杯 / 鞋 / 衣   ← 家里：随时能看到
日 / 月 / 山 / 水 / 火 / 木 / 花 / 草  ← 象形：字形本身就是画
走 / 看 / 吃 / 玩 / 睡 / 大 / 小       ← 动作与形容词
```

**卡片是两页**（`card.py: render_zika`）：

- 第 1 页：一个大字（128px）+ 底下一个词例（"刷牙"）
- 第 2 页：词里出现它（「刷**牙**」，目标字高亮金色）+ "找一找：家里哪里有它？"

**用法**：家长页「认一个字」点一个字 → 设备先播「牙，刷牙的牙」→ 屏幕出字卡
（B 翻页，A 退出）。你指着卡片问"牙刷上的牙在哪里？"

> 识字卡的语音是**预录**的（0101–0130），所以能离线播；
> 服务器换字只换图，不用重烧固件。

### 识字和习惯自动联动（推荐开）

不用你每天想着推卡——**习惯完成的那一刻，对应的字自己出来**：

| 习惯 | 自动推的字 | 时机 |
|---|---|---|
| 刷牙 | 牙 | 刷完按 A → 星星亮 → 屏幕出现「牙」 |
| 洗澡流程 | 水 | 同上 |
| 出门流程 | 门 | 同上 |
| 收玩具 | 玩 | 同上 |
| 按时起床 | 日 | 同上 |
| 喝水 | 杯 / 户外 | 草 / 帮忙 | 手 / 绘本 | 月 / 穿衣 | 衣 / 穿鞋 | 鞋 |

流程是连贯的：**按 A → 星星亮 → 语音"牙，刷牙的牙" → 屏幕出字卡 → B 翻页看词，A 退出**。
设备在打卡成功后会立刻同步一次，所以卡片基本是秒出，不用等 15 秒轮询。

**开关**：家长页「认一个字」下面有「习惯完成后自动推一张字卡」，默认开。

> ⚠️ **别把 4 个习惯全开**。每个习惯都会推一张卡，一天 4 张就成了打扰。
> 建议只给 1–2 个最稳定的习惯开自动推送（比如刷牙 + 洗澡），
> 其余的字在你想教的时候手动点。
>
> 更重要的：**一天 1 个新字就够，第二天先把昨天的复习一遍**。
> 5 岁半的记忆靠重复，不靠数量。

**为什么这个联动有效**：字出现在它该出现的那一刻（刚刷完牙，手里还拿着牙刷），
这叫**情境学习**——记忆线索是当时的动作和场景，不是卡片本身。
比坐在桌前认字卡有效得多。

### 复习机制：间隔重复，但不考试

学过的字会按 **1 / 3 / 7 / 15 天** 再出现一次，四次之后"毕业"不再自动复习。

```
学会「牙」  →  第 1 天复习 → 第 4 天 → 第 11 天 → 第 26 天 → 毕业
（间隔取 1、3、7、15，每次复习完自动排下一次）
```

**关键设计：复习不做对错判定。**

5 岁半不需要"你记住了吗"的考试——那会把识字变成压力。复习只是**再见一次**：

> 设备播："还记得这个字吗？牙，刷牙的牙。" → 屏幕出现「牙」字卡

他记得就记得，不记得就再看一眼。**没有任何分数、没有红叉、没有"忘了"这个状态。**

**什么时候复习？** 设备**每天第一次同步**时（早上开机或跨天）自动推一张到期最早的字卡。
一天只推一次，有幂等保护，不会重复。

**家长页「复习队列」**可以看到：

```
牙 · 第 2/4 次复习 · 下次 11-02   [现在复习] [学会了]
```

- **现在复习**：立刻再推一次（他今天状态好，想多看一眼）
- **学会了**：毕业，不再自动复习（你觉得已经稳了）

**另外两条保护**：

1. **一天最多自动教一个新字** —— 完成习惯时，如果今天已经教过，就不再推新的（否则 4 个习惯 = 4 个新字，孩子记不住，你也累）
2. **卡片消息只保留最新一条** —— 旧的卡自动作废，不会积压把新卡挤掉

## 八点九、成长档案：这一年留下了什么

主页放着一个入口：**📖 成长档案** → `/album`。

它不增加任何新动作，只是把已经发生的事**沉淀**下来：

```
景阳 的成长档案
从 2026-10-30 开始 · 第 43 天 · 角色「小豆豆」
   12/30 认识的字   7/9 问过的问题   126 完成次数   11 最长连续

【许多个「第一次」】
  第一次做到        2026-11-01 · 刷牙
  认识的第一个字    2026-11-03 · 牙
  问的第一个问题    2026-11-05 · 为什么树叶会变黄

【字卡墙】30 格，学过的亮起来，点开能看词例
【问题册】每个问题 + 当时的答案，按时间排
```

**为什么这个功能值得做**：

- 它服务主线（好奇心 + 每天做到），但**不需要任何新动作**——纯沉淀
- 它不引入新的进度货币——墙上是"会了什么"，不是"得了多少分"
- 它有一个孩子能理解的形式：**指着数"我会了 12 个字"**
- 它有一个家长需要的形式：**右下角「打印」，可以装订成一本**

> 这是整个产品的"毕业作品"。
> 设备会退役，但这本册子会留下来。

**刻意没做的事**：档案**不在设备上显示**。设备只做"今天的仪式"，档案是回头看的东西——
一旦放到设备上，它就会变成新的刷屏内容，违反第四条设计原则（只做仪式不做监控）。

## 九、四周迭代计划（别一次做完）

| 周 | 目标 | 验收 |
|---|---|---|
| **W1** | 只做"看得见的进度"：屏幕 + 2 个按键 + 星星 + 连续天数（不联网、不接语音） | 孩子愿意按一下试试 |
| **W2** | 接 DFPlayer + 提醒语音，角色有反应 | 孩子听到声音会抬头 |
| **W3** | 联网 + 家长页 + 家长认可通道 | 孩子听到"爸爸给你点了个赞"有反应 |
| **W4** | 让孩子参与：给它起名字、贴贴纸、决定第 4 个习惯 | 孩子主动去碰它 |

**真正的验收指标只有一个**：第 7 天，孩子**自己**走过去按了按钮，而不是你提醒他。
如果没达到，不要加功能——先改**时机和台词**（多半是提醒太晚、台词太长、星星不够显眼）。

## 十、排错

| 现象 | 原因 / 处理 |
|---|---|
| 屏幕黑 | 90% 是 **BL 脚没接或没拉高**；其次查 CS/DC 有没有接反 |
| 花屏 / 全白 | SPI 线序错。以代码里的宏为准，别信接线表的颜色 |
| 编译报 `Arduino_Canvas` 未定义 | Arduino_GFX 版本太旧，升到 1.6.5+ |
| 编译报内存/分区不足 | 分区选 **Huge APP**；确认 PSRAM 选的是 OPI PSRAM |
| 串口打 `canvas FAIL` | PSRAM 没开。自动降级为直接写屏（会有轻微闪烁），能用 |
| DFPlayer 没声音 | ①RX/TX 要交叉（ESP TX→模块 RX）②串 1k 电阻 ③上电后等 1.5s 再 begin ④喇叭接 SPK1/SPK2 ⑤SD 卡必须 `mp3/0001.mp3` 这种 4 位命名 |
| 屏幕上是英文 | 正常。Arduino_GFX 默认没有中文字库，中文全部走语音 |
| 屏幕上没有天数了 | 故意的。5 岁半看不懂数字，改成顶部 7 个格子（本周完成情况） |
| 只有 2 颗星 | 故意的。5 岁半只放 2 件事，星星才够大够醒目 |
| 家长页打不开 | 手机和电脑不在同一 Wi-Fi；或 macOS 防火墙拦了 Python |
| 打卡在家长页看不到 | 设备串口敲 `s` 手动同步一次；再敲 `q` 看离线队列里有没有积压 |
| 改了习惯数量，设备没变 | 等 15 秒，或长按 B 立即同步；串口敲 `h` 可以打印设备当前的习惯表 |
| 星星数量和页面不一致 | 同上。设备只在同步后更新，不是实时推送 |
| 时间不对 / 提醒不响 | 没连上 Wi-Fi 就没有 NTP 时间；提醒功能依赖联网 |

按键：**短按 A** = 完成当前习惯 · **长按 A** = "你教教我"（角色示弱）· **短按 B** = 切换习惯 · **长按 B** = 立即同步

串口命令（115200）：`t` 试音 · `r` 重置今天 · `s` 立即同步 · `q` 查看离线队列 · `h` 打印习惯表 · `p` 切换四幕（晨/昼/暮/夜）· `d/D` 屏幕自检 · `G` 几何自检 · `T` 触摸原始数据 · `1/2/3/8` 直接播对应编号

## 十一、等孩子用稳了，再考虑这些

1. **睡前故事**（这是唯一值得接 LLM 的地方）：孩子点"听故事" → 云端生成 60 秒故事 → TTS 播放。注意加内容白名单和时长限制。
2. **NFC 打卡**：贴纸贴在牙刷杯、书包上，刷一下才算完成——比按按钮更难作弊。
3. **第 4 个习惯**：让孩子自己投票决定，参与感比奖励更有用。
4. **周报**：周一早上给家长一封"上周完成率 + 一句建议"。
5. **外形**：3D 打印一个圆脸外壳，屏幕当眼睛——孩子的第一反应永远是"它长什么样"。
