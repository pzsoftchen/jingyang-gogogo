# 设计评审：三个功能之后，这个产品到底成了什么

> 评审对象：习惯养成 + 问题罐 + 基础识字（ESP32 桌面设备 + 家长页）
> 评审立场：不是夸，是找问题。找不出问题说明没看懂。

---

## 一、一句话判断

**主张是对的，但产品正在从"一个东西"变成"一堆功能"。**

它最珍贵的东西只有一句：**AI 不即兴对孩子说话，爸妈的话由设备送达，习惯是仪式而不是考核。**
这句话支撑了全部设计。但三个模块是**叠加**上去的，不是从这句话里**长出来**的。

---

## 二、产品的真实主张（值得守住）

| 主张 | 落在哪 | 是否成立 |
|---|---|---|
| AI 不直接对孩子生成内容 | 问题罐：AI 写给大人，大人审核后才播 | ✅ 成立 |
| 爸妈的认可不能被 AI 替代 | 0031–0040 由家长选、家长录音替换 | ✅ 成立 |
| 不用积分/兑换/排名 | 星星不换东西，徽章只是描述能力 | ✅ 成立，但正在变味（见 §4.2） |
| 5 岁半不识字也能用 | 屏幕只有图形/星星/格子，话全走语音 | ✅ 成立 |
| 只做仪式，不做监控 | 没有红叉、没有失败画面 | ✅ 成立，但"撤回"功能是个例外 |

**一个我必须指出的事实**：主张里说"AI 不直接对孩子说话"，但设备的语音全部是 TTS 合成的
（小豆的声音就是 AI 的声音）。所以真正的原则不是"孩子听不到 AI"，而是：

> **AI 不即兴生成内容，只播放被审核过的固定语料。**

这个区别很重要——它把"内容安全"变成了"内容清单"，是可验证的。建议把这条写进原则里，措辞改准。

## 三、三个模块的结构性问题

### 3.1 注意力预算超支（最严重）

算一下孩子一天要碰几次设备：

| 来源 | 次数/天 |
|---|---|
| 习惯打卡（1–4 件） | 1–4 |
| 习惯联动自动推字卡 | 1（已限流） |
| 每日复习字卡 | 1 |
| 问题罐答案 | 0–1 |
| **合计** | **3–7 次** |

对 5 岁半，**一天 3 次是仪式，一天 7 次是噪音。**
更糟的是：这 7 次里有 4 次长的都一样（星星亮 + 语音 + 屏幕变化），孩子会开始**按 A 关掉它**——
一旦他学会"关掉"，整套仪式就失效了。

**这是产品当前最大的风险，不是 bug，是结构。**

### 3.2 四种进度货币

| 模块 | 货币 | 孩子能理解成什么 |
|---|---|---|
| 习惯 | 星星 / 连续天数 / 7 格 | "我做到了" |
| 成就 | 徽章（第一天/三天火苗/一周不倒…） | ？ |
| 识字 | 字卡 / 复习阶段 | "我又认了一个字" |
| 问题罐 | 问题卡 | ？ |

**四种货币，孩子只会问一个问题："星星有什么用？"**
诚实答案是"没什么用"——那这四套系统就都是装饰。
前面立过"不做积分商城"的规矩，这是对的；但**同时做四套进度条，等于变相在做积分**。

### 3.3 家长是单点瓶颈

| 模块 | 需要家长做什么 |
|---|---|
| 习惯 | 陪跑、抽查、撤回、看周回顾 |
| 问题罐 | 户外记录 → 回家写答案 → 审核 → 念给孩子 |
| 识字 | 翻页、念字、第二天复习配合 |
| 全局 | 配置习惯、改名字、配 API Key |

**任何一周家长忙，三个模块同时停摆。** 自用产品最常见的死法不是没人用，是"累了就不用了"。

### 3.4 定位漂移：从"生活工具"滑向"早教机"

设备原本的独特价值是**关系**（爸妈的声音 + 一起做事）。
识字模块加进来后，产品开始有"内容供给"的味道——而内容是牛听听、火火兔、平板的战场，
而且那个战场的评价标准是"内容量"。

**这个产品打不赢内容军备竞赛，也不该打。**
它的护城河是"这台机器里只有我家的事"。

## 四、具体问题清单

### 4.1 家长页正在变成仪表盘（11 张卡片）

现在的家长页：5 岁半提示 / 连续天数 / 今日习惯 / 最近 7 天 / 能力徽章 / 本周回顾 /
问题罐（输入+列表+预览+推送）/ 认一个字（30 格+绑定+复习队列+开关）/ 发语音 / 最近发出 / 设置×3。

**仪表盘会诱导家长从"陪孩子"转向"看数据"。**
而我们在体系文档里写过："别看完成率，看他愿不愿意走过去。"现在产品在鼓励看完成率。

### 4.2 徽章系统是多余的

它和星星高度重复，而且"能力徽章"这个名字暗示了能力评估，但实际只是计数
（完成几天/打卡几次）。**建议砍掉**，把"能力"的表达留给周回顾的一句话。

### 4.3 问题罐的孩子侧闭环是断的

孩子的体验只有一句"我们一起看看答案"，然后家长念。
他的问题被回答了，但**他感受不到"我的问题被认真对待"的实物**。

问题罐 80% 的价值在家长侧（了解孩子在想什么、给谈资）。
这不是错，但要认清：**它是家长工具，不是儿童功能。**
认清之后就不该期待孩子对它有反应，也不该把它当成"第三个儿童功能"。

### 4.4 "撤回"破了"没有失败画面"的原则

撤回是必要的家长安全阀，但它把"孩子可能没做"制度化地记录进了系统。
建议保留，但在文案上明确：**撤回只用于"按错了"，不用于"没做"**——没做就是星星不亮，不需要撤回。

### 4.5 技术债已经不小

| 项 | 现状 |
|---|---|
| 固件 | 单文件 889 行，无自动化测试，无编译验证 |
| 协议 | `H=` 行已到 10 个字段，靠位置解析，加字段就全链路改 |
| server | 1558 行，全靠 curl 手测 |
| 语音包 | 120 条，改台词要重跑脚本 + 换 SD 卡 |

**每加一个功能要动三处**（server 协议 / 固件解析 / 语音包），这是可持续性的临界点。

## 五、建议：从"三个功能"回到"三个时刻"

### 5.1 核心收敛：一天只给孩子 3 个时刻

| 时刻 | 时间 | 内容 | 谁发起 |
|---|---|---|---|
| **早上** | 起床 | 今天要做什么 + 出门流程 | 设备 |
| **放学后** | 回家 | 一个惊喜：字卡 / 问题答案 / 爸妈的话（三选一） | 设备 |
| **睡前** | 洗漱 | 洗澡 → 刷牙 → 复习字卡 → 晚安 | 设备 |

**规则：惊喜三选一，不叠加。** 今天推了字卡，今天就不推问题答案。
内容源还是三个模块，但出口只有一个。

### 5.2 统一货币：星星只表示"我做到了"

- 星星 **不换任何东西**（现在就是这样，守住）
- 字卡和问题卡 **不是奖励，是内容**（不要给它们加"解锁"逻辑）
- 砍掉徽章、砍掉"连续天数"的显性展示（只留 7 个格子）

### 5.3 家长页从仪表盘改回"今天做什么"

建议首屏只留三块：

1. **今天**（3 个时刻的状态 + 一键操作）
2. **给景阳的一句话**（发语音）
3. **他的问题**（问题罐，默认折叠）

其余（徽章、周回顾、7 天、复习队列）全部折叠到「更多」，一个月看一次就够。

### 5.4 加一个真正缺的东西：成长档案

现在有"今天"（孩子侧）和"本周"（家长侧），**没有"这三个月"**。

建议做一个「相册」：

- 认过的字排成一面墙（他会想指着数"我会了 12 个字"）
- 问过的问题编成一本小册子（打印出来就是一个成长记录）
- 不是数据报表，是**可以给他看、可以打印、可以留下来的东西**

这是唯一值得新加的功能。因为它把三个模块沉淀成一个东西：**这一年的证据。**

### 5.5 给产品一个"毕业"设计

5 岁半的孩子，三个月后大概率对设备失去兴趣。这是硬件产品的宿命，不用对抗。

**不如把它变成产品叙事的一部分**：

> 它陪你走过幼小衔接这一年，然后退役。
> 退役的时候，你可以把这一年认的字、问的问题打印出来，装订成一本。

这个定位会让所有设计更克制——**因为你知道它只需要撑 12 个月，不需要做成平台。**

## 六、优先级

| 优先级 | 事项 | 理由 |
|---|---|---|
| **P0** | 三个时刻模型：惊喜三选一，一天 ≤3 次交互 | 不解决，功能越多体验越差 |
| **P0** | 家长页首屏收敛到 3 块 | 家长疲劳是最大死因 |
| **P1** | 砍徽章，弱化连续天数 | 减少货币种类 |
| **P1** | 成长档案（字卡墙 + 问题册） | 唯一值得新加的功能 |
| **P2** | 协议加版本号 + 服务端关键路径测试 | 技术债 |
| **P2** | 问题罐的儿童侧闭环（他能"看到"自己的问题被回答） | 提升不大，但是情感点 |
| **P3** | 字卡历史浏览、随身版、实时问答 | 都是加法，暂缓 |

## 六点五、落地记录（P0 已完成）

评审里提的 P0，已经改完了：

| 事项 | 结果 |
|---|---|
| **三个时刻模型** | 新增"每日惊喜"调度器：一天只推一个，按主线优先级挑（问题答案 > 复习卡 > 不给） |
| **家长页首屏收敛** | 首屏从 11 张卡收到 3 块：今天的惊喜 / 今天要做的 / 给他说一句话；问题罐、进度、识字、设置全部进折叠 |
| **新字不占惊喜名额** | 新学的字仍在"习惯完成那一刻"出现（情境学习），但一天最多一个 |
| **主线原则写进产品** | README 顶部加了主线图和"新功能准入五问" |

**P1 也做完了**：

| 事项 | 结果 |
|---|---|
| **成长档案** | 新增 `/album`：字卡墙（30 格）+ 问题册 + 许多个「第一次」+ 可打印。纯沉淀，零新增动作，零新增货币 |
| **刻意没做** | 档案不上设备——一旦上设备就会变成刷屏内容，违反"只做仪式不做监控" |

**还没做的**：徽章没砍（等观察一个月再决定）、问题罐的儿童侧闭环（P2）。

---

## 七、一句话总结

> 这个产品现在有**三个好功能**，但还**不是一个好产品**。
> 好功能靠加法，好产品靠减法。
> 下一步该做的不是第四个功能，而是**决定哪三个时刻最重要，然后把其余的全部收进去。**
