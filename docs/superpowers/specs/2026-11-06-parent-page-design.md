# 家长页 · 与设备同一套语言的暖色工具

> 状态：设计草案，待批准
> 日期：2026-11-06
> 范围：家长端 `/`、`/quick`、`/album` 的视觉与第一屏信息架构；设备状态与音量。
> 不包含：设备端主界面（另见 `docs/superpowers/specs/2026-11-06-sun-ui-design.md`）、新内容模块、账号体系。

---

## 一、为什么做

家长页目前是深蓝黑工具，设备端已经变成暖纸 + 小豆豆的一天。两边像两个产品：家长在手机上看到的，不是孩子在设备上感受到的那个世界。

但家长页首先是工具：家长多在晚上、用手机、快速看一眼或改一件事。它不是儿童主界面的放大版，不需要把太阳弧线、四幕背景、全屏角色搬过来。

目标：**同一套视觉语言，不同的使用密度。**

- 同一套暖纸/深蓝、薄荷/珊瑚、圆角卡片、小太阳角色。
- 家长页第一屏只回答"今天要做什么"。
- 细节全部收进一个「更多」，不变成仪表盘。

---

## 二、用户与场景

- **家长**：晚上孩子睡后打开，主要做三件事：看今天状态、发一句话、处理问题；白天偶尔补记问题或改设置。
- **设备**：1.85C 圆屏，家长页在同一局域网（`192.168.8.254:8099`）。
- **成功的样子**：打开后 5 秒内知道今天的三件事；改一个设置不需要翻三屏；夜间不刺眼。
- **失败的样子**：页面变成数据看板，家长开始盯连续天数/完成率；或者视觉很可爱但操作更慢。

---

## 三、目标 / 非目标 / 反目标

### 目标

1. 视觉与设备端同一套语言：暖纸/深蓝、太阳/睡帽太阳、薄荷/珊瑚。
2. 第一屏收敛为三个时刻 + 一条待处理提示。
3. 设备状态一眼可见；音量可调。
4. 保持纯标准库 + 单页 HTML，不引入前端框架。
5. 不增加家长每天的操作步骤。

### 非目标

- 不做图表、完成率看板、排行榜、连续天数上首屏。
- 不做账号/登录/多孩切换。
- 不做实时推送/WebSocket；仍用刷新 + 表单。
- 不做独立 App 或底部 Tab 栏（Phase 1 用单列 + 一个「更多」）。
- 不改变设备端主界面设计。
- 不新增内容推送或进度货币。

### 反目标（做了也算失败）

- 家长开始为了"好看的数据"而催孩子。
- 页面信息变少但操作变深（每件事都要点三次）。
- 夜间打开是亮白/亮黄大屏。
- 设备端和 `quick`/`album` 仍然是深色，只有首页换了皮。

---

## 四、已确认的设计决定

来自 2026-11-06 的 mockup 评审：

1. 第一屏：**3 张卡 + 一条待处理提示**，不是 4 张卡。
2. 白天/夜晚两套主题，**跟随本地时间**，可在「更多」里手动切换。
3. 标题旁放 **小太阳/睡帽太阳**；不铺满、不做弧线。
4. 顶部一条**设备状态胶囊**：在线/最后同步 + IP + Wi-Fi 信号。
5. 设备详情（电量/音量/版本）收进「更多 → 设备」；音量滑块在里面。
6. 问题罐用轻提示露出；完整列表在「更多」。
7. 家长页只做工具，不复制儿童主界面的布局。

## 五、视觉系统

### 5.1 主题

两套主题，共用同一组 token：

| Token | 白天（暖纸） | 夜晚（深蓝） |
|---|---|---|
| 页面背景 | `#FFF8EC` | `#1B2340` |
| 卡片 | `#FFFDF7` | `#242E4F` |
| 描边 | `#EADAC6` | `#3A466F` |
| 正文 | `#3E3228` | `#FFF4D6` |
| 次要文字 | `#8B735E` | `#9EA9C8` |
| 珊瑚（今天/主按钮） | `#E76F51` | `#FF8A65` |
| 薄荷（完成/在线） | `#2F6F63` / 填充 `#5BC8B0` | `#5BC8B0` |
| 浅底（chip/图标底） | `#F3E5D3` | `#2E3B63` |
| 太阳 | `#FFB703` | `#F4C56A` |
| 睡帽 | `#7C6FD6` | `#7C6FD6` |

- 圆角：卡片 18px，输入/按钮 10–12px；1px 描边 + 很轻的阴影。
- 不使用纯白/纯黑；不使用红色作为失败色。
- 状态不只靠颜色：完成有勾/星，今天有更大尺寸/外圈，离线有文字。

### 5.2 标题与角色

- 标题行：小太阳 46px + 左侧 `景阳`（21px）/ `今天 11月6日 周五 · 5–6 岁`（12px）**左对齐**；时间 `09:41` 放在右上角（11px）。
- 日期/时间由服务端渲染为 `DAY_CN`、`WEEKDAY_CN`、`NOW`；刷新页面更新，不做秒级实时时钟。
- 所有正文左对齐；只有按钮文字居中。不要继承父页面的居中样式。
- 夜晚：同一角色戴睡帽、闭眼，光芒变短变暗；不换成另一个角色。
- 角色只出现在标题和空状态；不做常驻动画；最多眨眼/静态。
- 右上角可放一个主题切换按钮（太阳/月亮），但 Phase 1 放在「更多」里也可以。

### 5.3 第一屏结构

1. **标题 + 状态胶囊**
   - 标题：左侧小太阳 + `景阳` + `今天 11月6日 周五 · 5–6 岁`；右上角 `09:41`（左对齐，不居中）。
   - 状态：`设备在线 · 12 秒前同步`
   - 第二行：`192.168.8.253 · Wi-Fi -72 dBm · 弱`
   - 离线：暖灰点 + `设备离线 · 最后同步 01-01 00:00`，不显示红色。
   - 孩子按了设备上的「告诉爸妈」时，顶部多一条**非卡片**细提示（复用现有 note banner）；不算第四张卡，但保持时间敏感。
2. **今天的惊喜**
   - 已给：显示今天给了什么；按钮可"明天再说"。
   - 未给：显示下一个（问题答案/复习卡）；按钮"现在就给 / 今天算了"。
   - 内容推送预算的说明只放在这里或更多，不占标题。
3. **今天要做的**
   - 1–4 件习惯；emoji + 名称 + 提醒时间 + 状态。
   - 完成用薄荷勾；未完成为中性；不显示红叉。
   - 一行小字："设备 x 秒前同步 · 误按可在更多里撤回"。
4. **给景阳的一句话**
   - 预置语音 chips（来自 `PRESET_PRAISE`）。
   - 备注输入（只显示在家长页；设备播放的是预置语音）。
   - 主按钮"发到设备上"。
5. **待处理提示**
   - 有未答问题/待补内容时显示：`有 2 个问题等你处理 →`。
   - 不做第四张大卡；点击滚动/展开到「更多 → 他的问题」。
6. **底部**
   - `更多 ⌄`（展开一个折叠区）
   - `成长档案` 链接（`/album`）

### 5.4 「更多」内容

按顺序收纳：

1. 他的问题：可回答项（`ask` + `draft`）置顶 + 最近 8 条已答 + 问题卡预览；`pending` 只出现在“待补内容”块，不再重复渲染；保留手动「记下来」输入。
2. 识字 / 复习队列 / 绑定的字
3. 本周回顾（旧"最近 7 天"保留在这里）与连续天数/最长（只给家长看）
4. 最近发出的认可 / 审批记录
5. 成长阶段
6. 习惯开关（1–4 件）+ 今天的打卡记录/撤回入口
7. 设备：IP / Wi-Fi / 电量（有 ADC 才显示）/ 音量滑块 / 协议版本与语音包版本
8. 设置：孩子名、角色名

「更多」用单个折叠区/单页分区，不要做多个并列卡片，避免首屏再次膨胀。

补充：

- 给景阳的一句话：10 条 `PRESET_PRAISE` 用**横向滚动**的 chips 展示，首屏卡片高度不随条数增长；不需要新选择逻辑。
- 今天的惊喜已给时，不再显示可点击的"明天再说"（`surprise_skip` 已无效果），只显示状态文字；没有新的"今天不再提"状态。
- 固件没有版本号：设备详情显示"协议 V2"与"语音包 voice.N"，不新增 `FW=` 行；以后要固件版本再单独加。
- `/quick` 与 `/album` 跟随首页的 day/night + 手动 localStorage 覆盖；`/album` 打印时强制暖纸浅色。

### 5.5 主题逻辑

- 白天：06:30–20:00；夜晚：20:00–06:30（与设备夜间边界一致）。
- 服务端渲染时根据本地时间给 `<body class="day|night">`；无 JS 也能正确显示。
- 「更多」里的太阳/月亮按钮可手动切换，写入 `localStorage`；手动选择优先于时间。
- 不使用 `prefers-color-scheme` 作为主逻辑；避免设备时间与手机系统主题不一致。
- 主题切换只换 CSS 变量，不改变页面结构。

### 5.6 设备状态与音量

设备状态（已在 main 工作树实现，见下）：

- 设备每 15 秒状态请求带 `rssi=`；服务端存 `devices.ip/rssi`。
- 在线：45 秒内有心跳；离线显示最后同步时间。
- 电量：需要确认 1.85C 是否有电池 ADC 采样脚；没有就显示"电量 —"，不造假。
- 状态胶囊首屏可见；IP/RSSI 也在首屏第二行；更详细的信息在「更多 → 设备」。

音量：

- 家长页滑块 0–100，存 `settings.volume`，默认 60。
- 服务端 `state.txt` 追加 `VOL=`；设备映射：
  - 1.85C：`audio.setVolume(round(vol * 21 / 100))`
  - DevKitC：`mp3.volume(round(vol * 30 / 100))`
- **跨端一起做**：本计划包含固件解析 `VOL=` 和 `set_volume()`（当前固件硬编码 `audio.setVolume(12)` / `mp3.volume(22)`）。这不是只改家长页就能生效的功能。
- **夜间 60% 由设备端应用**：服务端只发用户设定的基准 `VOL`；设备在本地夜间时段把实际音量压到 60%（例如设定 60 → 实际 36），避免睡前过响。这样断网/服务端不可用时仍能保持夜间安静。
- 本 worktree 基于已提交代码，实施前需要先把 main 工作树里的 1.85C 显示/触摸/状态改动合并进来（或按计划 cherry-pick）。
- 不做设备端音量手势；长按已用于同步/记录。

### 5.7 `/quick` 与 `/album`

- `/quick`：暖纸/深蓝、单输入框、最近列表；功能不变，只换 token/标题/按钮。
- `/album`：暖纸/深蓝成长档案；字卡墙、问题册、第一次；可打印；不引入新数据。
- 两者都跟随首页的 day/night（本地时间）与手动 localStorage 覆盖；否则家长在首页选了夜间、点进 album 又变亮，会割裂。
- `/album` 打印时强制暖纸浅色（`@media print`），不受夜间/手动主题影响。

```text
 [发到设备上 →]

```

孩子按了「告诉爸妈」时，在标题和卡片之间插入一条非卡片细提示；不改变 3 张卡的结构。

### 文案原则

- 标题写孩子名和今天，不写"每天最多推 X 次内容"；预算移到惊喜卡/更多。
- 不出现"完成率/连续/排名"在首屏；周回顾放更多。
- 设备状态用"在线/最后同步"，不用"设备已连接"这种技术词。
- 问题提示用"等你处理"，覆盖"回答"与"补内容"两种状态。
- 所有按钮是动作，不是指标。

## 七、技术实现方向

- 纯标准库 + 单页 HTML；不引入前端框架/打包器。
- `PAGE` 模板改为 CSS 变量 + `body.day/night`；`render_page` 传入主题。
- `render_page` 新增 `DAY_CN`、`WEEKDAY_CN`、`NOW` 占位符；标题/日期/正文显式左对齐，时间放右上角。
- 状态胶囊复用 main 工作树里已实现的 `device_status()`/`devices.ip/rssi`；本 worktree 分支基于已提交代码，实现前需要把 main 的未提交状态改动合并/迁移过来。
- 音量：`settings.volume` + `VOL=` + 家长页滑块；**固件端 `set_volume()` 与夜间 60% 压缩也属于本计划**；本分支实现前先合并 main 的 1.85C 固件改动。
- `/quick` 用同一套 CSS 变量；`/album` 的 `ALBUM_CSS` 换 token。
- 主题切换：服务端类 + 可选 localStorage 覆盖；无 JS 时按时间。
- 不改变现有路由、表单字段、PRG 行为；不新增鉴权。
- 测试：
  - 现有 69 个测试全绿；
  - 新增主题选择纯函数（时间→day/night）测试；
  - 音量保存/读取/边界（0/60/100）测试；
  - 状态胶囊/问题提示文本测试；问题提示计数覆盖 `draft`；
  - `/quick`、`/album` 包含主题类/占位符替换测试；album 打印强制浅色；
  - 日期/时间占位符替换测试（`DAY_CN/WEEKDAY_CN/NOW`）。
- 可访问性：16px 基准、44px 触控目标、对比度；颜色不是唯一状态信号；表单有 label。
- 响应式：单列，最大 520px；手机优先；不出现横向滚动。
