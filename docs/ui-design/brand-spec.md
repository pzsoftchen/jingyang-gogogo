## 字体

- **显示 / 正文**：`"PingFang SC", "Hiragino Sans GB", "Noto Sans SC", system-ui, sans-serif`
  - 字重 400 / 500 / 600；标题 600，`letter-spacing: -0.02em`。
  - 不用衬线体：这个品牌的表现力在形状和颜色，不在字形。
- **等宽 / 数字**：`"SF Mono", "JetBrains Mono", ui-monospace, Menlo, monospace`
  - 时间、页码、亮度、尺寸、token 值。
- **设备端**：没有中文字库。只有 Arduino_GFX ASCII 位图（1×/2×）与 40×40 的 3D 图标位图。
- **卡片**：PingFang SC；以 240 为基准，12 / 13 / 15 / 18px，识字大字 128px。
- **家长页**：21 / 16 / 13 / 12px；时间 11px；连续天数 40px；卡片圆角 18px，输入/按钮 10–12px。

## 观察到的视觉规则

1. **无字之屏。** 孩子的屏幕上不出现中文；所有“话”由语音说出。文字只活在卡片与家长页。
2. **一屏三层。** 顶部周弧（r=150）→ 中心太阳（本体直径 104px）→ 底部贴纸弧（r=140）。没有导航、卡片、图标栏。
3. **时间是主题。** 四幕只换光、背景和姿势；不换布局、不换角色、不换信息层级。
4. **进度是空间。** 一个点、一个星、一条弧；没有百分比、分数、排行榜、连续天数首屏。
5. **没有失败态。** 没有红叉、扣分、失败画面；点已完成只会说“已经做过啦”。

## 形状与尺寸

- 屏幕：360×360 基准（240×240 同比例缩放）。
- 太阳：中心 `(180, 170)`，本体半径 52，光芒外缘 90，五官深棕 + 亮色高光。
- 周弧：半径 150，圆心 (180, 180)，跨度 ±48°，7 个点对应周一到周日。
- 习惯弧：半径 140；1 件 0°、2 件 ±16°、3 件 ±28°/0°、4 件 ±42°/±14°。
- 贴纸：半径 30，奶油底 `#FFFDF4`，边 `#F3D6A8`；图标 40×40 位图。
- 卡片安全边距：26/240 ≈ 10.8%；圆屏，所有内容不得越过内切圆。
- 一切皆圆：圆屏、圆弧、胶囊、999px 点；家长页卡片 18px，无尖角。
