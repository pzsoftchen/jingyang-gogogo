01 / Four phases

一天四幕，只换光。

四个硬边界决定背景、太阳颜色和亮度；布局、角色位置、信息层级完全不变。切换时颜色在 2 秒内过渡。

06 / Parent tool

同一套语言，不同的密度。

家长页是工具，不是儿童主界面的放大版。首屏三张卡 + 一条提示，其余收进「更多」。

01

标题 + 设备状态

小太阳、孩子名字、今天日期；在线/最后同步、IP 与 Wi-Fi 信号。

02

今天的惊喜

一天只有一个。没给时显示下一个；不占内容预算。

03

今天要做的

1–4 件习惯，emoji + 名称 + 提醒时间 + 状态。完成用薄荷，不用红叉。

04

给景阳的一句话

10 条预置语音横向滚动；设备会念出来。备注只留在家长页。

05

一条待处理提示

“有 2 个问题等你处理 →”。不是第四张卡。

06

更多 + 成长档案

问题、识字、回顾、设备、设置都收进单个折叠区；首屏不做仪表盘。

主题

白天 06:30–20:00，夜晚 20:00–06:30；跟随本地时间，也可手动切换。白天暖纸、夜晚深蓝，同一组 token。连续天数与完成率不上首屏。

07 / Rules & gaps

八条规则，五处偏差。

规则来自已批准的设计与代码；偏差是提取时能直接看见的断层。

01

无字之屏

设备上不出现中文；文字只出现在卡片与家长页。

SCREEN
02

一屏三层

周弧 / 太阳 / 贴纸。没有导航、卡片、图标栏。

LAYOUT
03

时间是主题

四幕只换光、背景和姿势；不换布局、不换角色。

TIME
04

进度是空间

点、星、弧线；没有百分比、分数、排行榜。

PROGRESS
05

没有失败态

没有红叉、扣分、失败画面。点已完成只说“已经做过啦”。

STATE
06

颜色各司其职

珊瑚=今天/完成，薄荷=已完成，金色=角色。珊瑚文字改用深色。

COLOR
07

一切皆圆

圆屏、圆弧、胶囊、18px 卡片；没有尖角。

SHAPE
08

夜间是减量

亮度 20%，动画减半，音量 60%。不是换一套皮肤。

NIGHT
P0

卡片层还是旧深色

已批准的暖纸卡没有落地，card.py 仍输出 #0D1117 / #FF6B9D / #FFD166。孩子在暖屏与冷卡之间跳变，像两个产品。

建议按暖纸 token 重渲染 card.py；夜间只压暗，不换卡。

P1

家长页「更多」仍是深色块

textarea、回顾块、slot 仍用 #12171d / #232a33，嵌在暖纸卡里。暖纸化只完成了外壳。

建议输入与回顾块换成 --surface / --panel，夜间再按深蓝 token 覆盖。

P1

珊瑚文字对比不足

#E76F51 在暖纸上 2.93:1。连续天数 40px 刚好低于 3:1，提示文字 14px 远低于 4.5:1。

建议文字统一 #B94A2E（4.87:1），珊瑚只做填充。

P2

周弧贴边

r=150、外圈 12，外圈直径约 324px，超过设计稿的 ~300px 安全内容；最上外圈距屏沿约 18px，在实体表圈上容易显挤。

建议半径收到 138–142，或整体下移 4–6px。

P2

夜间装饰只存在于设计稿

云、月亮、星星、睡眼罩、弯曲光芒未进固件；代码只有直光芒与 “z z”。家长页的 emoji 与设备 3D 图标也仍是两套图标语言。

建议先补月亮/星星（静态、零动画成本）；睡眼罩、弯曲光芒与图标统一后置。

08 / Tokens

把系统带走。

六色语义 token + 四幕变量；hex 与 OKLch 一一对应。珊瑚文字使用派生 token。
