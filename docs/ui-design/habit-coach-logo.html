01 / Structure

太阳、周弧、今天、手。

四个元素，缺一个就不是小豆豆：太阳是角色，周弧是一周，珊瑚点是今天，弯曲光芒是手。

01

太阳本体

半径 62 / 256。深棕五官、奶油高光、腮红；它不是图标里的太阳，是有表情的角色。

02

周弧

半径 96，7 个点，跨度 ±48°。4 个薄荷完成、1 个珊瑚今天、2 个暖灰未来；这是设备顶部周弧的缩小版。

03

今天点

珊瑚 #E76F51 + 深棕环。全标识里只出现一次；它标记“今天”，不是奖励。

04

弯曲光芒

从半径 70 到 94，再向上弯。产品里说“光芒就是手”；这条弯光线就是挥手。

Safety

画布 256×256；标识四周留白 ≥ 31px（0.5× 太阳半径）。全标识最小 64px；紧凑标识最小 24px；横向组合最小宽度 240px。

03 / Versions

白天、夜晚、单色。

同一套几何，三种工作方式；颜色只换，形状不动。

日间 / 全彩
暖纸上的默认版本；珊瑚点只出现一次。
夜间 / 深蓝
太阳变浅，今天点变珊瑚；用于设备与夜间页。
单色 / 深棕
印刷、压印、单色丝网；所有细节走线条。
单色反白 / 奶油
深色底上的单色版本；不改变线的粗细。

06 / Don'ts

四条底线。

识别来自比例、颜色关系和那个珊瑚点；不要让它们漂移。

DON'T
不要拉伸
只允许等比缩放；太阳不能变成椭圆。
DON'T
不要旋转
周弧必须朝天；歪头不是角色的姿势。
DON'T
不要改色
不要换掉太阳金、薄荷完成或珊瑚今天。
DON'T
不要加效果
不加阴影、渐变、描边或发光；平涂就是它的质感。

ALLOWED等比缩放；单色或反白；在留白内放置；在暖纸、夜蓝、奶油三种底色上使用；直接使用原始 SVG。
