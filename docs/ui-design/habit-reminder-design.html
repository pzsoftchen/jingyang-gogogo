03 / Boundaries

提醒只说一次；
没做也不追问。

产品原则 · 不会生气的提醒者

01

每天一次

一个习惯一天最多叫一次；没有 snooze、没有每 5 分钟重复。

02

只提醒没做的

已完成、全部完成、未启用、今天不提醒 → 都不响。

03

固定语音

到点说哪一句由音频包决定；家长在设置里看到原文，AI 不即兴。

04

孩子屏幕上没有时间

没有倒计时、没有红点、没有“错过”；只有太阳说话 + 一圈光。

05

夜间轻声

20:00 后亮度 20%、音量 60%；仍然只提醒一次，不用亮白屏。

06

冲突先错开

同一分钟只保留一个提醒；两个提醒至少隔 5 分钟；流程会占用 0/7/12 分钟的窗口。

07

不做通知

不推手机、不做红点、不统计未完成、不上排行榜。

08

离线不补

提醒依赖设备 NTP；离线时不响，联网后也不补发。家长页会显示设备离线。

04 / Implementation

接到现有链路上。

设备端已经有 checkReminders 和固定语音；这次只加家长侧的编辑与三个状态，不改提醒引擎。

已有

不需要重写；只需要把现有值暴露给家长。

  • HABIT_PRESETS每条习惯已有 hh/mm 和提醒语音。
  • H=状态行已带 h/m；设备按分钟触发。
  • checkReminders已完成/当天已提醒会跳过；0:0 = 不提醒。
  • rt / rtSeq单句提醒，或流程的 0/7/12 分钟序列。
  • 夜间20% 亮度、60% 音量已经是现成行为。

新增

新增字段都在服务端；音频包不动。

  • remind_hh/mm每习惯的每日提醒时间。
  • remind_on每天提醒开关；0:0 仍表示不提醒。
  • remind_skip_date“今天不提醒”的日期；次日自动失效。
  • POST /parent/reminder保存时间/开关/跳过；服务端做冲突校验。
  • H= 末尾 skip新增字段，旧固件忽略；新固件跳过当天。
  • 设备光晕目标贴纸 1.5 秒柔和光圈；不新增音效。
# 现有状态行（h/m 已经在传）
H=toys|收玩具|0||4|5|19|40||0

# 新增末尾 skip：旧固件按前 10 段解析，忽略末段
H=toys|收玩具|0||4|5|19|40||0|0

# 家长保存（服务端校验后写入；不改音频）
POST /parent/reminder
habit=toys&hh=19&mm=40&on=1&skip_today=0

规则：同一分钟禁止保存；间隔 < 5 分钟也要求错开；流程窗口 0/7/12 分钟保留。

05 / Scope

这次不做。

让提醒保持小。孩子 5 岁半，需要的是一个不会生气的提醒者，不是一个更响的闹钟。

NO / REPEAT

不做重复提醒

没有 snooze、没有每 5 分钟一次；没做也不追问。

NO / RED

不做红点/未完成

“已过”是中性文案；不统计错过，不制造补救压力。

NO / PUSH

不做手机推送

提醒只发生在设备上；家长页不变成通知中心。

NO / SCHEDULE

不做周几排程

v1 只有“每天”与“今天不提醒”；自定义录音也在 v1 之外。

V1 范围

每习惯一个每日时间 · 每天开关 · 今天不提醒 · 冲突校验 · 夜间轻声 · 设备光晕。先跑两周，看孩子是否更主动走过去；如果他开始躲屏幕，先降难度或换时间，不要加提醒频率。

提醒设计基于 HABIT_PRESETS 的 hh/mm、H= 状态行和 checkReminders。固定语音、夜间亮度/音量沿用现有实现；本次不新增音频、不做手机推送。
