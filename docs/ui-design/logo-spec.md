# 小豆豆的一天 · 标识规范

> 2026.11 · 与 `brand-spec.md`、`habit-coach-design-extraction.html` 配套。
> **一句话：一个太阳，带着它的一周。**

## 一、概念

标识不是一个泛用的太阳图标，而是项目里已经成立的四件事：

| 元素 | 含义 |
|---|---|
| 太阳本体 | 小豆豆本人：深棕五官、奶油高光、腮红 |
| 周弧 7 点 | 设备顶部的周一到周日；4 个完成、1 个今天、2 个未来 |
| 珊瑚今天点 | 全标识唯一的珊瑚色；标记“今天”，不是奖励 |
| 弯曲光芒 | “光芒就是手”；右侧那条向上的弯线就是挥手 |

这是“一个太阳 + 一周”的组合，不是“太阳 + 装饰”。换掉任何一件，标识就不再是这个产品。

## 二、几何

画布 **256 × 256**，所有尺寸按等比缩放。

- 太阳：圆心 `(128, 136)`，半径 `62`。
- 面部：眼睛 `(112,130)` / `(144,130)`，半径 `7`；高光半径 `2.5`；腮红 `(100,153)` / `(156,153)`，半径 `8.5`；嘴为 `M116 152 Q128 164 140 152`，描边 `6`。
- 周弧：半径 `96`，7 个点，角度 `-138° … -42°`，跨度 `±48°`。
- 点状态：4 个薄荷完成（`r=5`）、1 个珊瑚今天（`r=5` + `r=7.5` 环）、2 个暖灰未来（`r=4.5`，`2px` 描边，`50%` 不透明度）。
- 光芒：从半径 `70` 到 `94`，`8px` 圆头；弯曲光芒从 `(198,136)` 弯到 `(222,102)`。
- 留白：标识四周 ≥ `31px`（0.5 × 太阳半径）。
- 最小尺寸：全标识 `64px`；紧凑标识 `24px`；横向组合最小宽度 `240px`；字标单独使用最小宽度 `180px`。

## 三、颜色

| 用途 | 日间 | 夜间 | 单色 |
|---|---|---|---|
| 太阳 | `#FFB703` | `#F4C56A` | `currentColor` 线稿 |
| 光芒 | `#FFB703` | `#E0AE58` | `currentColor` |
| 面部 | `#3E3228` | `#4A3B32` | `currentColor` |
| 腮红 | `#FF8FA3` | `#FF8FA3` | —（线稿省略） |
| 完成点 | `#5BC8B0` | `#5BC8B0` | `currentColor` 实心 |
| 今天点 | `#E76F51` | `#FF8A65` | `currentColor` 环 + 点 |
| 今天环 | `#3E3228` | `#FFE8A3` | `currentColor` |
| 未来点 | `#75604A` 50% | `#6B7A9E` 50% | `currentColor` 50% |
| 高光 | `#FFF8EC` | `#FFF4D6` | — |

- 珊瑚只出现在“今天点”一处；不要把它用作第二个装饰。
- 金色只属于太阳与光芒；不要给点、文字或背景加金色。
- 单色版本是线稿：太阳轮廓 `6px`、眼睛实心、嘴 `5px`、光芒 `8px`；不靠填色区分层级。

## 四、组合

| 版本 | 用法 | 最小尺寸 |
|---|---|---|
| 横向组合（符号 + 字标 + 描述） | 家长页、文档、包装 | 宽度 240px |
| 符号单独 | App icon、设备启动、单色印刷 | 64px |
| 竖向组合 | 封面、贴纸、方形版位 | 符号 96px |
| 字标单独 | 已建立认知的窄版位 | 宽度 180px |
| 紧凑符号 | favicon、页眉、≤64px | 24px |

- 横向组合的符号与字标垂直居中；字标与描述左对齐。
- 不要改变符号与字标的大小比例；不要给字标加描边或阴影。
- 字标使用 **PingFang SC 600**，字距约 `-0.025em`；描述使用等宽 **12px / +0.18em**。
- `logo-lockup.svg` 中的字标是活字；对外分发前请转曲。符号文件（`logo-mark*.svg`、`logo-mono.svg`、`logo-night.svg`、`favicon.svg`）不依赖字体。

## 五、应用

- **App icon**：`app-icon.svg`，512 / 1024；暖纸底、符号居中；圆角由系统裁切。
- **Favicon**：`favicon.svg`，32px 使用紧凑符号；奶油圆底，深色标签栏上也可见。
- **家长页页眉**：38px 紧凑符号 + 16px 字标；标识不进入儿童主屏。
- **设备**：设备主界面已经是小豆豆本人；标识只用于启动/包装，不叠加在四幕界面上。

## 六、禁止

1. 不要拉伸、压扁或旋转。
2. 不要改太阳金、薄荷完成或珊瑚今天。
3. 不要加阴影、渐变、发光、描边或 3D 效果。
4. 不要增加/减少周弧点数，不要把“今天”换成其他颜色。
5. 不要在低对比、繁忙照片或彩色渐变上直接放标识；使用留白或单色版本。
