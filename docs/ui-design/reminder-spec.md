# 小豆豆的一天 · 每习惯提醒设计

> 2026.11 · 与 `habit-reminder-design.html` 配套。
> **结论：建议加，但只加一层——家长可以给每个已启用的习惯改一个每日提醒时间；设备到点只播一次固定语音。不做重复提醒、红点、手机推送、周几排程、自定义录音。**

## 一、先看清现状

项目里其实**已经有提醒引擎**，缺的是家长能改它的 UI：

| 已有 | 位置 |
|---|---|
| 每条习惯的 `hh/mm` 提醒时间 | `server/server.py` · `HABIT_PRESETS` |
| `H=` 状态行里的 `h/m` | `state_as_text()` |
| 按分钟触发的提醒 | 固件 `checkReminders()` |
| 提醒语音 / 流程 0/7/12 分钟序列 | `rt` / `rtSeq` |
| 夜间 20% 亮度、60% 音量 | 四幕主题 / `applyVolume()` |
| 已完成、当天已提醒的跳过 | `remindedToday` / `done` |

现在家长页只能勾选“开哪几件”，时间来自预设；提醒时间本身不可编辑。这次设计补的是：**每习惯时间编辑、每天开关、今天不提醒、冲突校验、设备光晕**。

## 二、体验

### 入口

家长页第一屏仍然是三张卡；不新增“提醒”卡，也不新增每天要做的动作。

- 在「今天要做的」每一行右侧放一个 **时间胶囊**（44px 触控目标）：`19:40 / 提醒`。
- 点时间胶囊 → 从手机底部升起提醒设置。
- 时间胶囊同时也是状态：`今天不提醒 / 恢复`、`不提醒 / 设置`、`已完成`。

### 设置弹层

- 大时间输入 + `−5 / +5` 分钟；支持原生时间选择器。
- **每天提醒** 开关；关闭后习惯仍在今日列表，只是不叫。
- **今天不提醒** 开关；只跳过今天，明天照常。
- 显示到点会说的**固定原句**：例如「送玩具回家。」家长知道自己孩子会听到什么。
- 冲突提示：同一时间或间隔 < 5 分钟 → 要求错开；提供「错开 5 分钟」。
- 保存 / 取消；只有一个主按钮。

### 设备端

到点时：

- 太阳做“说话”表情；
- 目标习惯的贴纸出现 **一圈柔和光晕**（1.5 秒）；
- 播一次该习惯的固定语音；
- 不显示时间、不显示文字、不撒星星雨、不出现倒计时。

> 不用“亮一颗星”做提醒：星星已经绑定“完成”，再拿它做提醒会混淆。这里改用一圈光，指向同一张贴纸。

## 三、状态

| 状态 | 家长页 | 设备 |
|---|---|---|
| 还没到点 | `19:40 / 还没` | 静默 |
| 到点 | `现在 / 正在提醒` | 光晕 + 一句语音，只一次 |
| 已经做完 | `已完成` | 不响 |
| 提醒已过 | `19:40 / 已过`（中性） | 不补发、不重复 |
| 今天不提醒 | `今天不提醒 / 恢复` | 今天安静，明天照常 |
| 关掉提醒 | `不提醒 / 设置` | 不响；仍可完成 |
| 时间冲突 | 弹层提示先错开 | 后一句会盖掉前一句，所以禁止 |
| 夜间 | `20:30 / 轻声` | 亮度 20% / 音量 60%，仍只一次 |

- “已过”不用红色、不写“错过”、不统计次数。
- “到点”只出现一次，不进入循环。
- 设备端没有红点、没有未完成计数、没有排行榜。

## 四、规则

1. **每天一次**：一个习惯一天最多叫一次；没有 snooze、没有每 5 分钟重复。
2. **只提醒没做的**：已完成、全部完成、未启用、今天不提醒 → 都不响。
3. **固定语音**：到点说哪句由音频包决定；家长在设置里看到原文；AI 不即兴。
4. **孩子屏幕上没有时间**：没有倒计时、没有红点；只有太阳说话 + 一圈光。
5. **夜间轻声**：20:00 后亮度 20%、音量 60%；仍然只一次。
6. **冲突先错开**：同一分钟禁止保存；间隔 < 5 分钟也要求错开；流程占用 0/7/12 分钟窗口。
7. **不做通知**：不推手机、不做红点、不统计未完成、不上排行榜。
8. **离线不补**：提醒依赖设备 NTP；离线时不响，联网后也不补发。

## 五、数据与协议

### 新增字段

```text
habits.remind_hh       INTEGER   -- 0-23
habits.remind_mm       INTEGER   -- 0-59
habits.remind_on       INTEGER   -- 1 每天提醒；0 关闭
habits.remind_skip_date TEXT     -- 'YYYY-MM-DD'；只跳过这一天
```

- 现有 `HABIT_PRESETS.hh/mm` 作为默认值；DB 有值时覆盖。
- `remind_on=0` 等价于原来的 `hh:mm = 0:0`（不提醒），但保留时间，方便重新打开。
- `remind_skip_date` 只在等于今天时生效；次日自动失效。

### 状态行

```text
# 现有，第 4 段是完成时间；没有完成时为空
H=toys|收玩具|0||4|5|19|40||0

# 新增第 11 段 skip（0/1）；旧固件读前 10 段，会忽略末段
H=toys|收玩具|0||4|5|19|40||0|0
```

`checkReminders()` 增加一个判断：`skipToday` 为真时跳过；其余逻辑不变。

### 家长保存

```text
POST /parent/reminder
habit=toys&hh=19&mm=40&on=1&skip_today=0
```

- 服务端校验：同一分钟禁止；间隔 < 5 分钟拒绝或返回提示；流程窗口冲突提示。
- 保存后只影响下一次匹配；**今天已经过去的时间不补发**。
- 不需要新增音频，也不需要改 `rt` / `rtSeq`。

## 六、边界与实现注意

- **NTP / 离线**：固件 `checkReminders()` 依赖 Wi-Fi + NTP；离线时不提醒。家长页顶部已有设备在线状态，不另做提醒。
- **夜间**：20:00 后仍在夜间主题；亮度 20%、音量 60%；提醒照常一次，但不亮白屏。
- **流程习惯**：`rtSeq` 的 0/7/12 分钟是流程窗口；不要把另一个提醒放在窗口里。v1 在 UI 里提示；更复杂的排程不做。
- **冲突**：同一分钟会触发多条 `say()`，后一句会打断前一句；因此 UI 和服务端都要拦。
- **今天不提醒**：不是把时间改成 0；保留每日时间，只写 `remind_skip_date`。
- **已完成**：勾选后取消当天提醒；仍可修改明天的时间。
- **未启用**：不在今日列表；不提醒；历史保留。
- **设备光晕**：目标贴纸外圈 36–37px、2.5–3px 描边、1.5 秒；跟语音一起出现，结束就散；不加音效。
- **音频**：不新增；提醒语音沿用 SD 卡里已有的 `rt` / `rtSeq`。
- **不做**：手机推送、红点、未完成计数、snooze、每 5 分钟重复、周几排程、自定义录音、孩子自己设时间（5.5 岁）。

## 七、v1 范围

每习惯一个每日时间 · 每天开关 · 今天不提醒 · 冲突校验 · 夜间轻声 · 设备光晕。

先跑两周，看孩子是否更主动走过去；如果他开始躲屏幕，先降难度或换时间，不要加提醒频率。

## 八、测试建议

- `toMin / addMin / phaseFor`：跨午夜、19:59→20:00、20:30 夜间。
- 冲突：同一分钟、4 分钟、5 分钟、关闭提醒、今天跳过。
- 保存：时间写入 DB；`H=` 的 `h/m` 正确；`skip` 只当天；次日恢复。
- 固件：`skipToday` 跳过；已完成/未启用不响；夜间亮度/音量；一次后 `remindedToday` 置位。
- 家长页：时间胶囊 44px；弹层焦点返回；开关可键盘操作；无红点/无“错过”。
- 设备：光晕只围绕目标贴纸；不出现时间/文字/星星雨；语音结束光晕消失。
- 离线：断网不提醒；联网不补发。
